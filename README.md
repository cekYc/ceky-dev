# 🚀 Eray (cekYc) — Multi-Department Developer Portfolio & Dev-Hub

Bu proje, iş başvurularında Teknik Liderlere, Mühendislik Yöneticilerine ve İK uzmanlarına sunulmak üzere hazırlanmış **çoklu departman uyumlu (Multi-Persona)** interaktif bir geliştirici portfolyosudur.

---

## ✨ Öne Çıkan Özellikler

1. **4 Departman Odaklı Dinamik Görünüm:**
   - ⚙️ **Backend Developer:** Go, NestJS, Supabase Postgres (RLS), Redis Streams, ACID, Microservices.
   - 🌐 **Full-Stack Developer:** Next.js App Router, Angular 17 Standalone, Cloudflare Workers, Three.js/WebGL.
   - 🦀 **Systems & Low-Level:** Rust, Vulkan Voxel Engine, Stage-0 Compilers, P2P Mesh Streaming, Saf C (C11).
   - 🖥️ **Bilgi İşlem / IT & Altyapı:** AIOps Radar v5.0 (Windows Win32/UAC), Wi-Fi RF Sinyal Haritalama, %100 Çevrimdışı Android/SQLite araçları.

2. **Gizlilik Korunmuş Özel (Private) Mimari Vaka Analizleri (Case Studies):**
   - Kaynak kodları ifşa etmeden `EloCode`, `deadly_sins_engine`, `ceky-lang`, `crm`, `valorant-premier` ve `cekypets` gibi en gelişmiş projelerin mimari şemalarını ve veri akışlarını sergileyen interaktif pencereler.

3. **İnteraktif CLI Konsolu (Terminal):**
   - Ziyaretçilerin `help`, `backend`, `systems`, `cat elocode`, `stats`, `skills`, `contact` gibi komutlarla doğrudan klavyeden gezinebileceği gömülü terminal.

4. **Yazdırılabilir / PDF Uyumlu CV Modu:**
   - Sağ üstteki **"CV / Yazdır"** butonu veya `Ctrl + P` ile seçili departmana özel temiz bir özgeçmiş sayfası oluşturur.

---

## 🛠️ Yerel Olarak Çalıştırma

1. **`preview.bat`** dosyasına çift tıklayarak tarayıcınızda anında açabilirsiniz.
2. Veya herhangi bir yerel HTTP sunucusu ile:
   ```bash
   python -m http.server 3000
   ```
   Tarayıcınızda `http://localhost:3000` adresine gidin.

---

## 🌐 Ücretsiz Canlıya Alma (Hosting) Seçenekleri

* **GitHub Pages:**
  Bu dizindeki dosyaları `cekYc.github.io` deponuza yükleyip GitHub Pages ayarlarından `Deploy from Branch (main / root)` seçtiğinizde anında yayına girer.
* **Cloudflare Pages / Vercel / Netlify:**
  Dosyaları sürükle-bırak yaparak 10 saniye içinde dünya çapında CDN üzerinde canlıya alabilirsiniz.
